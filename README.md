# PlatePlan

Madplan og indkøbsliste på et lille budget. Træk retter ind i ugekalenderen, og få en samlet indkøbsliste og ugepris for det antal personer, du laver mad til.

- `index.html`: Viser appen i en telefonramme på computer og sender mobiler direkte videre til appen.
- `app.html`: Selve appen. Den kan installeres på hjemmeskærmen (PWA) og virker offline.

Appen hostes med GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
